Putting one back

The half nobody tests until the day they need it

Download the file from Drive, put it on the server, and: 

python run.py restore project-control-backup.zip

It prints what is in the backup — which projects, how many deliverables — and asks before writing anything, then keeps the database it replaced beside the new one. Restoring is deliberately not a button on this page: it throws away everything since the backup was taken, and that should take more than a mis-click. The database in use is {{ database }}.
