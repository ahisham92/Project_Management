This page is a front door, not the app

GitHub Pages can only serve static files. Project Control is a Python application with a shared database behind it, so it has to run on a host that executes Python — otherwise there is nowhere for everyone’s progress updates to be stored together.

Put it online in a few minutes, then come back and add the address to this page:

  1. Deploy the repository to a host that runs Python and keeps its files — PythonAnywhere’s free plan does both, and the repository also ships a render.yaml, a fly.toml and a Dockerfile for other hosts.
  2. Set SECRET_KEY and HTTPS_ONLY=true on the host.
  3. Open /register on the new address — the first account created is the administrator.
  4. Edit the single APP_URL line at the top of docs/index.html and push — this page then becomes a link straight into it.

Full instructions are in the repository’s README, under Sharing it with your team.

What it does

  • PortfolioEvery project you manage, ahead or behind, at a glance.
  • ProgressDeliverables carry weights; status steps set the percentage.
  • ScheduleWhat is late, due soon, or behind plan — with every workflow date.
  • BudgetHours booked against budget and against the progress they earned.
  • RevisionsComments raise a revision and reschedule the submission.
  • ReportsPrint or save any tab as a PDF for management.

Running it on your own computer

No hosting needed if you only want it for yourself:

pip install -r requirements.txt
python run.py seed
python run.py --open

It opens at http://localhost:8000. Only that machine can reach it, so use a host if the team needs to share it.
