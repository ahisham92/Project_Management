    Assumed readings over {{ life }} years

    Until the real sensors are connected, each planned sensor tells a simulated story over the whole design life, the shape an engineer would expect: corrosion slowing as rust builds, chlorides creeping in, cracks opening, strain riding the seasons with the odd hard berthing. The line marks the year picked.

    The sensors on their own

    A small file with only the planned sensors instead of the whole model: each at its host element's position, with its tag, kind, product, host and how it is installed.

    Sensors as IFC Sensors as CSV

    • IFC: every sensor an IfcSensor with an MT_Sensor property set, in the same coordinates as the model it came from. In Revit, Insert, Link IFC, and it sits on the model; in Navisworks or any IFC viewer, append it.
    • CSV: one line per sensor with its tag, host element and GlobalId and position, for a schedule, a logger's channel list, or readings: put the tag in the first column of a readings file and import it under Set up, Sensor readings.
