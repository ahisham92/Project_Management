Read the elements from the Revit model

An IFC export of the model (.ifc or .ifczip), or a schedule or material takeoff exported from Revit as text (.txt, .csv) or Excel (.xlsx). It ticks what it finds and reads the concrete grades.

How to export it from Revit
  • IFC (everything): File → Export → IFC. Pick IFC4 Reference View or IFC2x3 Coordination View 2.0, leave "Export only elements visible in view" unticked, and export. Upload the .ifc.
  • A schedule (quicker): View → Schedules → Material Takeoff, choose Multi-Category, add the fields Category, Family and Type, Material: Name and Material: Volume. Then File → Export → Reports → Schedule, and upload the .txt.
  • The .rvt file itself cannot be read here: Revit keeps its models in its own closed format that only Revit opens.
