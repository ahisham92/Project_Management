This address is reserved for the comment response sheet application. It is mounted as an application of its own rather than built into this one, so it keeps its own data and its own pages and neither has to know how the other works.

To install it

Put a package called crs beside app, with a create_app() that returns a Flask application: 

Project_Management/
  app/            ← this application
  crs/
    __init__.py   ← def create_app(): ... returns a Flask app
  wsgi.py

That is the whole contract. Nothing here needs changing: this page stops appearing the moment the package is importable, because wsgi.py mounts whatever it finds in front of this address.

If it lives somewhere else

Set CRS_APP to yourmodule:your_factory to mount an application that is not in a package called crs. Set CRS_URL to a full web address to make this door a link instead — for a comment response sheet that is deployed on its own and only wants pointing at.
